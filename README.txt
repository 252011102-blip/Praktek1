CANARYNEST — PROJECT WEBSITE PENJUALAN BURUNG KENARI ONLINE

Isi folder:
- index.html       : halaman utama, kartu produk, carousel
- katalog.html     : katalog produk kenari
- panduan.html     : panduan perawatan dan checklist
- tentang.html     : profil toko dan komitmen layanan
- pemesanan.html   : formulir pemesanan
- style.css        : desain responsif dan komponen UI
- assets/site.js   : menu mobile, carousel, validasi formulir
- gambar/*.jpg     : foto burung kenari untuk halaman produk
- gambar/*.svg     : ilustrasi burung kenari buatan khusus untuk project

Cara menjalankan:
1. Ekstrak ZIP.
2. Buka folder di Visual Studio Code.
3. Buka index.html dengan browser atau gunakan ekstensi Live Server.
4. Navigasi antarhalaman tersedia melalui menu di bagian atas.

Catatan:
- Formulir berjalan sebagai simulasi front-end; belum terhubung ke database, WhatsApp API, atau payment gateway.
- Nama produk, harga, usia, dan stok adalah konten contoh untuk demonstrasi website, bukan penawaran stok aktual.
- Ilustrasi SVG adalah aset grafis tematik yang disertakan secara lokal sehingga tidak memerlukan gambar dummy atau koneksi internet.
